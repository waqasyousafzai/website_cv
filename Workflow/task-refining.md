# Task Refining

## 1. Invocation Example

```markdown
@task-refining.md execute on @task-file.md /grill-me
```

## 2. Refinement

1. Challenge the tasks for clarity, completeness, scope, and actionability. 
2. Change only what improves execution; leave sound tasks unchanged. 
3. Rewrite, split, combine, reorder, or remove tasks as needed while preserving the intended outcome.

## Output Rules

1. Edit the target file directly; do not create a separate review file.
2. Change the target file wherever needed to make every task completely clear and actionable.
3. Resolve every ambiguity before finishing; ask targeted questions when necessary, then update the target file with the answers.
