# Task Refining

## 1. Invocation Example

```markdown
@task-refining.md execute on @task-file.md /grill-me
```

## 2. Refinement

Challenge the tasks for clarity, completeness, scope, and actionability. Change only what improves execution; leave sound tasks unchanged. Rewrite, split, combine, reorder, or remove tasks as needed while preserving the intended outcome.

Invoke the mattpocock Grill Me skill for this refinement process. 

## Output Rules

- Edit the target file directly; do not create a separate review file.
- Change the target file wherever needed to make every task completely clear and actionable.
- Resolve every ambiguity before finishing; ask targeted questions when necessary, then update the target file with the answers.
